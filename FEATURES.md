# Spice Paradise - Feature Documentation

## 🎨 Indian Theme Design

### Visual Elements
- Custom logo with Indian-inspired mandala design
- Gradient backgrounds using saffron, turmeric, and red colors
- Gold accents throughout the interface
- Traditional Indian decorative elements (diyas, patterns)
- Poppins font for modern yet elegant typography

### Color Psychology
- Saffron Orange: Represents energy and enthusiasm
- Turmeric Yellow: Symbolizes prosperity and warmth
- Deep Red: Signifies passion and appetite
- Gold: Represents luxury and quality
- Cream: Provides warmth and comfort
